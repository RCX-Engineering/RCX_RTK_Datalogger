This is the source code for the RTK Base ntrips caster. This will need to be configured prior to use. 

We recommend public casters use Centipede for Europe and rtk2go in the US, though both are global.
rtk2go is unforgiving of configuration errors and quick to temporarily ban ips: 
  Test with a temporary unpublished Centipede mount point before establishing a permanant. 

See the documentation from Centipede and rtk2go for more details. 
Centipede Mount Points are 4-5 characters, letters and numbers only.
